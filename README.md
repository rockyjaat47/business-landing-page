# Business Landing Page

Responsive one-page website for small businesses — services & prices, products, timings, Google Map, WhatsApp enquiry form, and a sticky WhatsApp / Call / Map bar on mobile.

Demos: `?demo=salon`, `?demo=cafe`, `?demo=gym`, `?demo=clinic`, `?demo=boutique`

Edit the `BUSINESSES` config at the bottom of `index.html` to set it up for a new client.
